# 📈 NIFTY 50 Last Week Analysis

This project downloads, cleans, and visualizes NIFTY 50 index data using Python.

## 📂 Features
- Line chart of closing prices
- Bar chart of trading volume
- Histogram of daily changes
- Animated price chart (matplotlib)

## 🔧 Technologies Used
- `pandas`
- `matplotlib`
- `yfinance`
